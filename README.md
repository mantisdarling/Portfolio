# Harshit Kumar — Portfolio Website

1:1 Minimalist Monochrome Portfolio featuring the Canvas Scatter Particle Engine & Cherry Blossom Developer Pixel Art.

## 🚀 How to Run
Simply open `index.html` in any web browser, or serve with:
```bash
npx serve .
# or
python -m http.server 3000
```

## 🌐 Deploying to Vercel / GitHub Pages
- **GitHub Pages**: Push this repository to GitHub, go to Settings -> Pages, and select `main` branch root.
- **Vercel**: Import this repository on [vercel.com](https://vercel.com) as a static HTML project.

## 🛠 Features
- **Monochrome Minimalist Layout**: Inspired by mannan.io with VT323 & 5×7 dot-matrix typography.
- **Canvas Scatter Particle Engine**: Real-time Hooke's Law spring physics on text and artwork with 0% idle CPU culling.
- **136.1 Hz Cosmic Om Drone**: Synthesizer powered by the Web Audio API with smooth fade-out toggle on the top-most `ॐ`.
- **Work Experience & Verified Credentials**: 6 real-world roles and 8 verified certifications with clickable SVG logo badges.
- **Full SEO & Accessibility**: Schema.org JSON-LD structured data, Open Graph, Twitter Cards, `sitemap.xml`, and `robots.txt`.
