# Harshit Kumar — Portfolio Website

1:1 Minimalist Monochrome Portfolio featuring the Canvas Scatter Particle Engine & Cherry Blossom Developer Pixel Art.

## 🚀 How to Run
Simply open index.html in any web browser, or serve with:
`ash
npx serve .
# or
python -m http.server 3000
`

## 🌐 Deploying to Vercel / GitHub Pages
- **GitHub Pages**: Push this repository to GitHub, go to Settings -> Pages, and select main branch root.
- **Vercel**: Import this repository on [vercel.com](https://vercel.com) as a static HTML project.

## 🛠 Features
- **Monochrome Monochrome Layout**: Inspired by mannan.io with Courier New typography.
- **Canvas Scatter Particle Engine**: Real-time Hooke's Law spring physics on text and artwork.
- **Seamless Cherry Blossom Artwork**: High-res developer desk pixel art with interactive particle scatter.
- **Live Scroll Breadcrumb**: Dynamic ~/ header tracking.
